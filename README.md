## Current Projects

### Products I own

- 🎓 **[programemos.dev](https://programemos.dev)** — Spanish learning platform: paths, exercises, projects, community, and an admin panel. Progression is part of the product (levels, streaks, badges). I designed it and I run it: Next.js, NestJS, PostgreSQL, Prisma, Auth0.
- 🧭 **[camilogaon.online](https://camilogaon.online)** — My site. The longer version of the work on this page.

### Systems in production

- 🏛️ **[Property tax — Municipality of Samaniego](https://camilogaon.online)** — Jul 2025 to May 2026. Sole developer, from the requirement to production. The rules for rates, surcharges, and discounts come from the municipal tax code. PostgreSQL and Prisma for the domain, NestJS for the API, Next.js for the staff UI, JWT for auth. I deployed it and stayed through rollout. I also wrote the proposal for electronic payments (PSE and cards) and a local business-tax module.

### Product engineering

- 🏢 **[ISWO](https://www.iswo.com.co/)** — Feb 2024 to Jun 2025. Software for ISO quality and HSEQ management. Scrum team. I shipped frontend and backend work in React, Next.js, and Python, and integrated a support assistant with Rasa and the OpenAI API so help stayed inside the product.
