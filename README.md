## Current Projects

### Tools

- 🔨 **[Forge](https://github.com/camilogaon/forge)** — TypeScript CLI, MIT, v0.1.0. `inspect` walks a directory, `read` prints a source file, `search` finds a text query. Next cut: ask a question about the repository and get an answer from the code. The repo is still local.

### Systems in production

- 🏛️ **[Property tax — Municipality of Samaniego](https://camilogaon.online)** — Jul 2025 to May 2026. Sole developer, from the requirement to production. Rates, surcharges, and discounts come from the municipal tax code. PostgreSQL and Prisma for the domain, NestJS for the API, Next.js for the staff UI, JWT for auth. I deployed it and stayed through rollout. I also wrote the proposal for electronic payments (PSE and cards) and a local business-tax module.

### Product engineering

- 🏢 **[ISWO](https://www.iswo.com.co/)** — Feb 2024 to Jun 2025. Software for ISO quality and HSEQ management. Scrum team. I shipped frontend and backend work in React, Next.js, and Python, and integrated a support assistant with Rasa and the OpenAI API so help stayed inside the product.
